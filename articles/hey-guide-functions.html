Guide: Functions

Functions, step by step

Index Guide 1: First steps Guide: Functions Reference: Functions
What you'll be able to do
  • Write a function, call it, and use what it returns.
  • Pass a function to another function, keep one in a variable, and return one.
  • Call functions with many arguments of any type, and call module functions such as Text.upper.
  • Read the error for each common mistake and know what to change.
Each step is a whole program you can run. Reference: Functions has every form in one place.

Badges: Works today compiled and run by the documentation test. Decided, coming ruled, not in a released build yet.

1. Define one, call it

Works today A function starts with fn, names its parameters, and hands back a value with return. There are no type annotations: Hey works the types out.

greet.hey

fn greet(name)
  return 'Hello, ' + name + '!'
end

program
  says greet('Ada')
end
$ hey greet.hey
Hello, Ada!

A function can call itself:

fact.hey

fn fact(n)
  if n <= 1
    return 1
  end
  return n * fact(n - 1)
end

program
  says fact(10)
end
$ hey fact.hey
3628800

2. Use the result, or say you don't need it

A function without a return gives nil. When you call a function only for what it does and don't want its result, write _ = in front, so a reader (and the compiler) can see you meant to drop it. A result dropped without _ = gets a warning. Decided, coming

discard.hey

fn note(text)
  says text
  return len(text)
end

program
  _ = note('logged')
  let n = note('kept')
  says n
end
$ hey discard.hey
logged
kept
4

3. Functions are values

Works today Write a function's name without calling it and you have the function itself. Pass it, keep it in a variable, return it from another function, then call it like any other.

values.hey

fn apply_twice(f, x)
  return f(f(x))
end

fn inc(n)
  return n + 1
end

fn double(n)
  return n * 2
end

fn pick(want_double)
  if want_double
    return double
  end
  return inc
end

program
  says apply_twice(inc, 5)
  let chosen = pick(true)
  says chosen(21)
end
$ hey values.hey
7
42

That's why Hey has no block parameter: where Ruby passes a block, you pass a function.

You'll be able to call any expression that gives a function, without naming it first: an element of a List, the result of another call, or a function kept in a record. Decided, coming

call_any.hey

fn inc(n)
  return n + 1
end

fn pick()
  return inc
end

program
  let fs = [inc]
  let ops = {up: inc}
  says fs[0](3)
  says pick()(5)
  says ops.up(1)
end
$ hey call_any.hey
4
6
2

4. Many arguments, of every type

Works today A function takes as many arguments as it needs, of any type: Int, Float, Bool, String, List, Map, and records (a Map literal with fixed keys, read with a dot). There's no fixed limit on the count.

mixed.hey

fn summary(count, ratio, ok, name, items, scores, point, a, b, c, d, e)
  return name + ' ' + count + ' ' + ratio + ' ' + ok + ' ' + len(items) + ' ' + scores['ada'] + ' ' + point.x + ' ' + (a + b + c + d + e)
end

program
  says summary(3, 0.5, true, 'run', [1, 2, 3], {ada: 9}, {x: 4, y: 5}, 1, 2, 3, 4, 5)
end
$ hey mixed.hey
run 3 0.5 true 3 9 4 15

Optional, named and gathered ("rest") parameters, and spreading a List or Map into a call, are in Reference: Functions. Decided, coming

5. Module functions

Works today Standard library functions live in modules and are called by their module name, such as Text.upper. Today you import the module first:

shout.hey

import 'stdlib:Text'

program
  says Text.upper('hey')
end
$ hey shout.hey
HEY

Standard library modules won't need the import: Text.upper('hey') will work on its own, because every built-in lives in its own namespace and can't collide with your names. Decided, coming Your own modules are imported as Reference 2 describes.

6. When a call goes wrong

Works today These are the messages the current build prints, at run time. The location line will point at your call, and the compiler will report each one before the program runs whenever it knows which function you're calling. Decided, coming

few.hey: too few arguments

fn add(a, b)
  return a + b
end

program
  says add(1)
end
$ hey few.hey
function add expects 2 arguments
hey error: function add expects 2 arguments
...

Pass every required argument. The same message comes for too many.

typo.hey: no such function

fn add(a, b)
  return a + b
end

program
  says ad(1, 2)
end
$ hey typo.hey
unknown function: ad
hey error: unknown function: ad
...

notfn.hey: calling something that isn't a function

program
  let n = 5
  says n(1)
end
$ hey notfn.hey
hey error: attempted to call a non-callable value: `n` is int
...

Reference: Functions lists every error, including the ones for named, optional and rest parameters.
