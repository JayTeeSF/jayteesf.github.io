Hey 553a: the last O(n²) falls.

String self-append — set s = s + piece, the last quadratic in the honest benchmark set — is now linear for compiler-proven accumulators. It was O(n²) because a str accumulator is a raw C-string: every + rebuilt a fresh string from the whole prefix. 553a lands Track C2: a proven unique self-append accumulator holds a persistent owned string and appends in place through the runtime's geometric fast path. The two dictionary levers (549a & 552a) and Distributed Hey (two-machine-verified at 551a) stay closed.

TL;DR

  • The last O(n²) is closed for the common case. set s = s + piece was quadratic because a str accumulator is a raw C-string — each + manufactures a fresh string value from the whole prefix before the concat can help, so the persistent thing is a char*, not a refcounted backing. The runtime already had a sole-owner, geometric, in-place append fast path; it was inert because the emitter never routed through it. 553a routes through it.
  • How (a general compiler fact, not a benchmark hack): the compiler licenses a unique self-append string accumulator — a str local seeded empty (let s = '') whose every reassignment is a self-append set s = s + piece (s is both the target and the sole left operand) and whose other uses are non-retaining borrows. A licensed accumulator holds a persistent owned HeyString; each append grows that one backing in place (doubling its capacity) instead of copying the prefix; a raw C-string is materialized only when the value is read out. The analysis is proven decoupled first, then the codegen; a load-bearing negative — an alias let old = s between appends — defeats the licence, so old keeps its pre-append bytes.
  • Receipt (O(n), by the allocation counter — not wall-clock): a named-function accumulator swept N = 500k→4M copies strdup_bytes 8.5M → 17M → 34M → 68M — exactly doubling per size-doubling (O(n)); string_grows goes 18→21 (O(log N)); total time ~2× per doubling. An alias-defeated twin at equal N copies strdup_bytes 4× per doubling (O(n²), 940×–3765× more bytes). The counter is the proof the whole-prefix copy is gone; wall-clock alone would not be.
  • Exact scope, stated plainly. The win applies to a compiler-proven self-append accumulator in a named function, read out by a bare print/return/store, lowered by the self-host emitter (the path the default compile uses). Three soundness-safe narrowings remain as filed follow-ups — a missed optimization is never a miscompile: (a) a top-level program-scope accumulator is licensed by the analysis but not yet lowered; (b) a len(s) read-out defeats the licence and falls back to the safe O(n²) path; (c) the native C reference emitter's mirror is deferred. The cross-language / cross-machine bench re-measure is pending on the maintainer's next cherry-pick.
  • All three O(n²) mechanisms are now closed (named apart). 549a closed the in-place map overwrite; 552a closed the interprocedural map update (the 1BRC shape, O(1)/op); 553a closes string self-append. This is not a language-wide owned-string ABI (that would be a later, separate representation change). Distributed Hey stays closed (landed + two-machine-verified at 551a).

How Track C2 works

The fix is a general compiler fact plus a runtime path that already existed. It was built in four steps, each proven before the next:

  • Analysis (decoupled, report-only first). The compiler recognizes a unique self-append string accumulator: a str local seeded empty, whose every reassignment is set s = s + piece (s is the target and the sole left operand, and piece does not re-read s), and whose every other occurrence is a non-retaining borrow. This is surfaced as a report line and mutation-proven — the positive is licensed; an alias (let old = s), an argument-pass, and a bare return are each refused — before any code generation depends on it.
  • Codegen (self-host emitter). A licensed accumulator's slot holds a persistent owned HeyString (seeded empty). set s = s + piece lowers to “load the string, append the piece in place, store it back” — the runtime's sole-owner fast path grows that one backing geometrically (doubling capacity) rather than copying the prefix. A raw C-string is materialized only when the accumulator is read out (returned, printed, or stored). Non-accumulator code is byte-for-byte identical.
  • Why the alias must defeat it. The in-place grow is safe only because the backing is provably sole-owned. Binding let old = s publishes a second reference to that buffer; if the licence still fired, the next append would corrupt old. So the alias defeats the licence and old keeps its pre-append value — verified behaviourally and by the analysis refusing the aliased function. The soundness guard is checked at run time too (hey_box_assert_sole), and a dedicated falsification aborts exactly when a backing is wrongly shared.
  • Conservative by construction. Where the emitter cannot yet prove or lower a shape — a top-level program-scope accumulator, a len(s)-style read-out, or the native reference emitter — it falls back to the ordinary raw-C-string path. That is slower (the old O(n²)) but never wrong. These are filed follow-ups, deliberately not a general owned-string rewrite of the language.

This is kept named apart from the two dictionary levers and the compiler-authority receipts. It removes a representation bottleneck the ownership machinery structurally could not reach.

Distributed Hey — closed at 551a (carried)

Nothing on the distributed track changed this cycle; it is recorded here as last-verified, not re-run. At 550a the v0 substrate landed as four attributable layers — native TLS server accept, a versioned binary Codec (measured O(n) encode), and the DistTransport/DistNode/DistRemote substrate with node identity + incarnation, backpressure, heartbeats, reconnect and remote monitors — and stale-incarnation rejection was enforced and falsified. At 551a the two-machine TLS L2 gate went green across all four legs on real hardware: a macOS node and a Linux node over fast ethernet ran Remote.call (TLS, reply=pong), Remote.send (tcp, at-most-once), the kill→NODE_DOWN monitor (tcp), and stale-incarnation rejection (TLS) — node A observed exactly the incarnation node B advertised, a genuine cross-host run. A published “How to run distributed Hey” walkthrough accompanies it. Verified honestly: examples run interpreted because the LLVM back end does not yet lower the cross-unit Dist*/Codec calls (the extern-facade frontier — the same frontier the P2 campaign now targets); the remaining rungs are the deterministic L3 partition / at-most-once matrix and a cluster registry. v0 guardrails held: no Registry/Rinda/Jobs/gossip, at-most-once with no auto-replay, and socket IO stays in its owning context (a documented deviation with a filed follow-up).

Verification & falsification

The version at stdlib/Version.hey now reads 0.99.553a; the 48 HIR/MIR goldens were regenerated for the version line only (the embedded language 0.99.552a → 553a and its content hash), with no body drift — Track C2's codegen change is emitter-only and the licence is report-only in the MIR.

  • Track C2 is proven, not just fast. The analysis is mutation-proven (spec 1354): the accumulator is licensed; the alias, argument-pass, and bare-return negatives are refused. The load-bearing negative — let old = s; set s = s + piece keeps old at its pre-append bytes — is a spec (1355) and a compiled run. Boundary cases (a materialized C-string at a str parameter; return/store with balanced releases and no over-free under the RC assert; a slice taken before continued appends stays intact) all hold. Ownership specs 1189 and 1346–1355 are green.
  • The O(n) claim is a counter, not a clock. On the named-function sweep, strdup_bytes doubles per size-doubling and string_grows is O(log N); an alias-defeated twin at equal N copies 4× per doubling. The answer is identical with copy-on-write on and off (HEY_RC_COW=0/=1) and the RC assert does not fire. The proof is the allocation shape, not the wall-clock.
  • Scoped honestly. Where the emitter cannot lower a shape it falls back to the safe O(n²) path; those cases (top-level scope, len read-out, native mirror) are filed follow-ups, and the ladder marks them as such rather than claiming universal linear sconcat.
  • Both prior levers carried: the 552a interprocedural-merge fix (flat K-sweep, verifier lockstep) and the 551a two-machine distributed gate remain green; nothing here perturbs them.

Glossary

Reference for the shorthand used above. We use codenames internally and they leak into these pages; rather than strip them out, they are defined here and used consistently day to day. Terms coined since the previous daily are marked NEW.

sconcat
String self-append, set s = s + piece in a loop. Was O(n²); the target of Track C2.
Track C2 NEW
The work that makes sconcat linear via a narrow persistent-owned-string accumulator — kept named apart from the map/ownership tracks.
self-append accumulator NEW
A str local seeded empty whose every reassignment is set s = s + piece and that is otherwise only borrowed. The shape the compiler licenses.
owned HeyString / backing NEW
A reference-counted string value with a growable buffer (the “backing”). An accumulator holds one and grows it in place; an ordinary str is a raw C-string (char*).
in-place append NEW
Growing the accumulator's one backing (doubling its capacity) instead of building a fresh string from the whole prefix each +. Turns O(n²) into O(n).
read-out NEW
The moment an accumulator's value is used (returned, printed, stored) — the one place a raw C-string is materialized from the owned string.
licence / defeats the licence NEW
The compiler’s permission to lower the fast path. An alias (let old = s), an argument-pass, or an unhandled read-out defeats it, and the code falls back to the safe O(n²) path.
strdup_bytes / string_grows NEW
Runtime allocation counters. strdup_bytes = total bytes copied (O(n) when linear, O(n²) when not); string_grows = geometric capacity doublings (O(log N)). The receipt’s proof, instead of wall-clock.
self-host emitter / native emitter
The two code generators. The Hey-owned (self-host) emitter is the default compile path and carries the Track C2 win; the native C emitter is the reference/bootstrap one (its mirror is a follow-up).
1BRC map cliff (552a)
The interprocedural set stats = merge(stats,k,v) map update that deep-cloned the whole map each time; closed at 552a to O(1)/op.
K-sweep
A benchmark that holds the total work fixed and varies the map size K; a flat time across K is the signature of O(1)/update.
extern-facade frontier
Cross-unit stdlib calls (e.g. Dist*/Codec) the LLVM back end does not yet lower to real symbols, so those examples run interpreted. The target of the P2 one-true-compiler campaign.
P2 / one-true-compiler NEW
The next main-thread campaign: close the extern-facade frontier so the Hey-owned pipeline lowers every construct, with the C emitter kept as runtime/ABI/bootstrap only — not a second semantic compiler.
COW (copy-on-write)
Sharing a value until it is written, then copying. Maps are COW by default since 547a; running with HEY_RC_COW=0 forces eager copies and is used as a soundness cross-check.
landed / verified / deployed
Landed = committed and through the checks. Verified = a named check reproduced the evidence. Deployed = on trunk, the state users feel. 553a is landed and stamped on trunk (local); a cross-machine re-measure is pending.
