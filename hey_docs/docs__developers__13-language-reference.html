Hey language reference#

This page is the compact source-language reference. It describes the settled contract consumed by the restructured frontend.

Source structure#

A source file may contain:

imports
module declarations
function declarations
actor declarations
worker declarations
job declarations
spec blocks
one program block

Comments begin with # outside strings.

Names#

A name begins with a letter or underscore and continues with letters, digits, or underscores. Function names may end in ? or !. A name cannot be punctuation alone and cannot begin with a digit.

Examples:

user
read_source_text
ready?
save!
_private_helper

Literals#

nil
true
false
42
3.5
'raw string'
"interpolated #{value}"
[1, 2, 3]
{name: 'Ada', active: true}

Binary/hexadecimal literal support and exact numeric spellings are defined by the tokenizer registry and conformance specs.

Bindings and state#

let name = expression

A binding never changes. set is a statement for actor/monitor/supervisor state slots only:

set count = expression
set count += expression
set count -= expression
set count *= expression
set count /= expression
set count %= expression

There is no assignment expression.

Functions#

fn name(required, optional = value, ...rest, named:, named_optional: value, ...named_rest)
  body
end

Defaults evaluate left to right. Functions are callable values and may be stored in arrays/objects or transported in actor/Job payloads. JSON encoding rejects callables.

A bound callable captures leading arguments in an owned environment:

let add_ten = bind(add, 10)

Modules#

module Name
  declarations
  exposes public_name forms: [:qualified, :unqualified, :dotted]
end

A module's exposes declarations are its complete public surface. Omitted declarations are not public. private fn makes an internal declaration explicit.

An exposed named function may declare an operator form:

exposes pow infix: '**'

Imports#

import 'stdlib:Module'
import './relative.hey'
import '../relative.hey'
import 'package:Module'

import './module.hey' as Alias
import './module.hey' exposing: [name]
import './module.hey' exposing: [old_name as new_name]
import './module.hey' exposing: *
import './module.hey' exposing: [name] forms: [:dotted]
import './module.hey' exposing: * conceals: [name]
  • Bare import creates qualified access.
  • as renames the module binding.
  • exposing: adopts public bindings into lexical scope.
  • old as new aliases one selected binding.
  • forms: narrows the forms adopted from the module exposure.
  • conceals: removes selected adopted/default bindings.
  • Import effects are file-local.
  • Re-export is explicit.

Selector lists are compile-time literals. Reusable surfaces use facade modules; runtime values cannot manufacture lexical imports.

Field, index, call, and receiver forms#

value.field
value[key]
call(arg, named: value)
receiver.call(arg)

A receiver call resolves statically to a selected function with the receiver as the first argument. A field access is not a method lookup. In a chain, each segment resolves independently.

Arrays and objects#

Create updated values rather than mutating:

[...items, next]
{...record, status: 'ready'}

Use collection functions such as put, remove, push, and merge when their intent is clearer.

Control flow#

if condition
  body
else
  body
end

for item in items
  body
end

while condition
  body
end

return expression

Actors add receive, send, lifecycle, link, monitor, and supervision forms. Workers/Jobs are documented separately.

Truthiness#

Only false and nil are falsey. Everything else is truthy.

Operator set#

FamilyOperators
Arithmetic+ - * / % **
Comparison== != < <= > >=
Boolean&& ` and or not !`
Bitwise& ` ^ << >>`
Range..< ..
Spread/rest...
State update statements= += -= *= /= %= after set
Member/index/call. [] ()

The tokenizer emits - without deciding whether it is prefix or infix. Parser context chooses the form. Precedence and associativity come from the operator registry. Imports may select the meaning of an overridable operator in one file; imports cannot alter parse shape.

Important settled groupings:

!a == b       # (!a) == b
not a == b    # not (a == b)
a && b || c   # (a && b) || c
a and b or c  # (a and b) or c

** is non-associative. Parenthesize chained exponentiation.

Numeric behavior#

  • Whole-number division truncates toward zero.
  • Whole-number division by zero is an error.
  • Decimal arithmetic follows floating-point behavior.
  • Whole-number overflow widens rather than silently wrapping.
  • % supports whole and decimal operands.
  • to_f() converts a whole number to a decimal.
  • Bitwise and shift operators require whole-number semantics.

Ranges#

1 ..< 5  # excludes 5
1 .. 5   # includes 5

Strings and multiline input#

Double quotes support interpolation and standard escapes. Single quotes are raw except for quote/backslash escapes. Fenced/heredoc forms are described in Multiline strings.

The parser continues a statement while (, [, or { remains open. There is no trailing-operator continuation rule.

Specs#

spec 'description'
  expect stdout "expected\n"
  expect stderr 'message'
  expect exit 1
end

Run embedded specs with:

./bin/heyc file.hey --test

Compiler contract#

source -> tokens -> final syntax -> resolved names -> HIR -> MIR -> LLVM

No stage after name resolution may reinterpret raw source to rediscover syntax or binding decisions.
