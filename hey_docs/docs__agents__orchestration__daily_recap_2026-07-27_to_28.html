Daily recap — 7:00 AM PT July 27 through 8:20 AM PT July 28

Source notes for the bench seat's daily article. Format per the

maintainer's standard: every item carries a STATUS tag —

[DONE ✓] completed AND verified, positive outcome

[DONE, MIXED] completed, but with a cost or a null result

[IN PROGRESS] running right now, not finished, no result yet

[FAILURE→FIXED] something went wrong, and the fix is verified

[FAILURE, OPEN] something is wrong and not yet fixed

[NOT DOING] decided against — do not resurrect

Every codename is defined at first use. Numbers are receipted in

the evidence ledger and landing messages (v0.99.443a–460a).

DECISIONS NEEDED FROM THE MAINTAINER

None pending. Every ruling asked for during this window was given

and is recorded (dataset anchoring, win ladder, 5-minute rule,

byte_buffer removal, import spelling, shim skip). The next

decision likely to reach you: naming/staging details when the

namespace implementation brief is written.

DID — the eighteen landings (all [DONE ✓] unless marked)

Releases v0.99.443a through v0.99.460a: each one fully verified

(both code generators byte-identical, ~100-program corpus survey,

regression battery), deployed to the trunk checkout your apps

run, and — from 459a on — pushed to the remote as well.

MEMORY AND SPEED

  • [DONE ✓] Loop-memory leak class: ZERO bytes retained per

iteration, both platforms (443a).

  • [DONE ✓] Nested-carrier leak class: zero; the "shed storm"

failure mode is dead (445a).

  • [DONE ✓] Web event core landed opt-in and won every Linux

benchmark rung (444a). (Event core = one thread waiting on many

connections, instead of one thread per connection.)

  • [DONE ✓] S3 in-place store (455a): storing into a 65,536-slot

table went from 329,333 ns to 11.6 ns — flat no matter the

table size. This was THE blocker on 1BRC aggregation.

  • [DONE, MIXED] Memory ladder stages (a)+(b) (448a/449a):

correctness and enabling value proven (race-free with the old

masking bugs removed; 24.6x on shared-structure writes) — but

the WEB-path speed win was FALSIFIED per the pre-registered

gate (+1.9%/-1.3%, a wash). Reported as such, not dressed up.

THE SILENT WRONG-ANSWER PURGE — seven classes of "compiled code

computes different values than the interpreter," none visible to

any existing test (all specs ran on the interpreter):

  • [FAILURE→FIXED] D1 (451a): boxed integers compared as TEXT —

`while received >= expected` with expected=10 exited at 2. Also

explained the fake "actor pool drops workers past 8" bug (pool

exonerated with pre-stated predictions).

  • [FAILURE→FIXED] F1 (454a): operator precedence — a - b * 10

compiled as (a - b) * 10; 24 of 52 measured shapes were WRONG

in the default build lane. Shipped that way for months.

  • [FAILURE→FIXED] F3+F6+F7+F8 (458a): trailing comments changed

compiled behavior — could flip a value's type, refuse valid

declarations, or (F7, the worst) silently DROP the rest of a

.map() chain: wrong list, exit 0.

  • [FAILURE→FIXED] F4 (459a): unary minus — interpreter said nil,

compilers refused; now numeric negation everywhere.

  • [FAILURE→FIXED] F9 (459a): pushing a string local printed its

POINTER ([4340083027] instead of ["hi"]).

  • [FAILURE→FIXED] Decoded-int subscript (460a): a JSON-decoded

integer could not index an array — the app team's HIGH bug.

  • [FAILURE, OPEN — fix IN PROGRESS] Typed-local coercion: a

string assigned into an integer-initialized local silently

becomes 0 across a function boundary (recorded a phantom quiz

vote on a classroom TV). Fixer running now.

GATES THAT MAKE THE INVISIBLE VISIBLE

  • [DONE ✓] The metamorphic gate (456a): every corpus program

builds three ways (original / comments stripped / comments

  • [DONE ✓] --check means checked (457a): zero false positives

  • [DONE, MIXED] --check now costs real compile time on 8 huge

compiler-internal files (~2-3 min each; everything else fast).

Accepted: correctness over speed; fast-path catalogued.

LANGUAGE HYGIENE

1BRC — the billion-row challenge

  • [DONE ✓] Correctness settled PUBLICLY: Hey's output exactly

matches the official oracle (413/413 stations, zero

disagreements, full scale, both platforms) — and THREE

reference implementations were wrong before Hey was (C min

bug, Python rounding, comma station names). The article line:

"right and slow; the bet is making it fast while it stays

right."

  • [DONE ✓] Dataset ruling executed: official 413-station file =

headline; our 41,344-station file = labelled stress row.

Comparators measured locally: C 12.0s / Python 59s (headline);

C 18.75s / Python 136-143s (stress).

  • [DONE ✓] The cardinality tax is REGIME-DEPENDENT: 4.6x when

data fits in cache, ~1.3x at full scale on a RAM-limited box

(memory pressure masks it). Each platform's pressure mechanism

population. (Bench retracted its own cross-platform claim with

  • [DONE, MIXED] Headline projection improved 23h -> 20.6h. Still

hours, not seconds — but 99.6% of per-row cost is now measured

  • [IN PROGRESS] The bet-bar rung (43s) is NOT runnable yet by the

~76,000). Blocked on the next compiler slices, not on anyone's

box. This is honest sequencing, not a delay.

GLOSSARY DELTA (for the public glossary)

transformed builds (comment-decorated vs bare must agree)

instead of fixed expected outputs.

F-family (F1, F3–F9) — this window's silent wrong-answer defect

classes; all dead except the typed-local fix in flight.

S1/S2/S3n — the stdlib consistency program: lowering coverage /

sugar consistency / namespace hygiene.

exposing — the ruled opt-in import form: import 'stdlib:X'

exposing fnY (or *); bare identifiers, no quotes.

minutes; climb a decade ladder, project from the flat slope.

~70-minute ladder at declared boundary landings.

to slowness: invisible at 73 us/row, dominant at 10 ns/row.
