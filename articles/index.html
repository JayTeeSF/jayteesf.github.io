  • Hey’s Arrays Now Tie C on Numbers. The String Wall Just Fell.

    Hey is immutable, so changing an array meant copying it — and two of eight benchmark workloads timed out at full size. A flat, typed-storage rewrite plus an in-place-write gate moved the numeric shapes to native class, and the shipped compiler has since closed the string wall too: on the same M3 Pro at v0.99.528a all eight workloads finish, byte-identical to C. The five numeric shapes tie or trail C by 1.08–2.5x and beat Ruby/YJIT by ~10–19x; the string builds finish at ~2.0s but still pay the immutability tax at ~4.5x C and a hair behind Ruby. Every loss is reported straight.
