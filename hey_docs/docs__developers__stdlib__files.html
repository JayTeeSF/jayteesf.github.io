stdlib:Files#

stdlib:Files is the single public filesystem module. It owns path helpers, file contents, traversal, metadata, staging/publication primitives, stateful file handles, and read-only mappings.

import 'stdlib:Files'

let path = Files.join('build', 'message.txt')
Files.write_text(path, "hello\n")
says Files.read_text(path)
says Files.basename(path)
says Files.dirname(path)

Discovery and traversal#

let markdown = Files.files('docs', '.md')
let entries = Files.entries('docs')
let sources = Files.hey_files('.')

Files.files uses the runtime recursive walker and returns a sorted array. Files.files_slow is the readable Hey parity/debugging implementation.

No-follow metadata#

let info = Files.metadata('build/message.txt')

says info.exists
says info['type']
says info['size']
says info.mode
says info.executable
says info.symlink

The type is file, directory, symlink, other, or missing.

Result-returning path reads#

Use Files.read_result(path) or Files.lines_result(path) when a missing path should be represented as data rather than terminating the program.

Stateful handles#

Import stdlib:Io to use the common receiver surface.

import 'stdlib:Bytes'
import 'stdlib:Io' \
  exposing: [write_all, seek, read_exact, sync, close] \
  forms: [:dotted]

let file = Files.open('build/data.txt', 'create_read_write').value
file.write_all('abcdef')
file.seek(0, 'start')

let read = file.read_exact(6)
says Bytes.decode(read.value.data, 'utf-8')

file.sync()
file.close()

File handles support sequential and positioned reads/writes, seek/tell, truncate, flush/sync, timeout configuration, EOF/closed state, and idempotent close.

Read-only mappings#

Automatic-lifetime mapping:

import 'stdlib:Bytes'

let mapped = Files.map_readonly('measurements.txt')
if mapped.ok
  let data = mapped.value
  let newline = Bytes.find_byte(data, 10, 0)
  let first = Bytes.slice(data, 0, newline)
  says Bytes.decode(first, 'utf-8')
end

Explicit lifecycle:

import 'stdlib:Io' exposing: [mapping_slice, close] forms: [:dotted]

let mapping = Files.open_mapping('measurements.txt').value
let view = mapping.mapping_slice(0, 128).value
mapping.close()
consume(view) # retained views remain valid

Closed mapping handles cannot create new views. Physical unmapping waits until every retained view is released.

Files.read_bytes_at(path, offset, count) provides a positioned copy when a mapping is inappropriate.

Staging and durable publication#

let stage = Files.temp_dir('build', 'package-stage')
Files.copy_tree('source', stage.value)
Files.make_executable(stage.value + '/bin/tool')
Files.write_atomic('build/state.json', state.json_canonical_text)
Files.move(stage.value, 'build/published')
Files.remove_tree('build/published.old')

Files.write_atomic writes and syncs a sibling temporary file, renames it into place, and syncs the parent directory. Tree copy rejects symlinks and staging remains on the destination filesystem.

Opaque handles expose only the lifecycle and I/O forms selected from stdlib:Io; they are not mutable application objects.
