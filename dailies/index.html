  • One limit was four walls. Three are down.

    The number everyone quoted as Hey's function ceiling was four separate defects sharing one symptom. This week took down three: a crash on module-wrapped programs, an entire class of depth crash — retired, not patched, by teaching the interpreter to eliminate self tail calls the way the compiler already did — and a cubic compile time cut 32x at 500 functions with byte-identical output. The fourth wall, a thirty-second parse deadline at about 2,850 functions, still stands, but its error message now names the knob that raises it. Underneath: the ownership ladder R0 through R5 landed, thirteen commits and thirteen version bumps, and corrections at claim volume — including every depth number in the tree quietly being a debug-build number worth a factor of three to four.

  • The loop stopped leaking. The request handler did not.

    A whole class of memory leak in built Hey programs is closed where the work repeats inside a loop: 403,792 KB down to about 2.2 MB, flat across a sixteen-fold sweep, with a hook that restores the old behaviour on demand. Full ladder R2 through R8, and a green code-generator gate measured against a bar the project already retired.
