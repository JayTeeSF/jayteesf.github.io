Hey language · compiler ruling · 22 August 2026

Emitter authority cuts over per construct

Hey is retiring the legacy C code generator that its self-hosted, Hey-written generator was built to replace. The question was not whether — it was when a piece of the language stops being graded against the old compiler's exact output.

● RULED · D49-c · contract-proven

Why this needed a ruling. Byte-for-byte identity with the native C emitter was already retired as the correctness bar — but it is still the live gate. So every improvement to the Hey emitter must first reproduce the C emitter's exact bytes, including the C emitter's mistakes. That is the one thing blocking the old compiler's removal. This ruling decides how authority transfers. It builds directly on D28 ("byte-goldens retire per-test, mutation-proven — not a date, not a milestone; each byte test first states what it was protecting, then is replaced by a test of that contract").

The three ways to cut over

D49-a Cut at current parity, now.

Freeze the goldens for the corpus the Hey emitter already routes, declare it authoritative there, keep native only as bootstrap. Rejected: 104 of 131 routed examples do not mean every construct inside them already has an independently falsifiable trust replacement.

D49-b Cut only at 100% coverage.

Keep byte-identity until the Hey emitter covers the whole corpus, then retire it in one move. Rejected, and worst of the three: it knowingly forces the new compiler to reproduce obsolete native implementation accidents after byte identity was already ruled not the bar.

D49-c Incremental per-construct cutover, contract-proven. — RULED

Authority moves forward only when earned, one construct family at a time — and native stops contaminating the parts of the new compiler that have already been proven. Crucially, the replacement is a contract test, not a frozen Hey byte snapshot: swapping "whatever native emits" for "whatever Hey emitted on cutover day" would just mint a new byte oracle.

The ruling

The Hey emitter becomes authoritative construct family by construct family. A construct leaves native-C byte-parity when all of these hold:

  1. the Hey path handles the construct without fallback;
  2. the relevant HIR / MIR / LLVM verifier gates pass;
  3. the language/ABI behavior the old byte comparison was protecting has an independent replacement test;
  4. that replacement has been deliberately mutation-proven to fail;
  5. applicable cross-surface behavior stays green — compiled / run / test / REPL, as appropriate;
  6. the cutover is recorded in a machine-readable frontier / ledger.

At that point native C ceases to be the correctness oracle for that construct, and a later difference from native is not a regression merely because the bytes differ. Native may stay as Stage-0 / bootstrap / recovery machinery until the fixed-point retirement gates permit deletion, but it does not regain semantic authority for a construct that has crossed the frontier. Exact-byte LLVM identity remains only where bytes are genuinely contractual — reproducible / fixed-point artifacts and ABI/serialization — never as the general language-correctness test.

Operational rules

  • Monotonic. Once a construct is Hey-authoritative, nobody solves a later problem by quietly putting its native byte comparison back into the gating path. If Hey is wrong, fix Hey against the semantic contract.
  • Construct-based, not example-based. "104/131 examples" is coverage telemetry; one example exercises twenty constructs. The ledger records each construct as Hey-authoritative / parity-transitional / unsupported, with the replacement gate that earned authority.
  • Trust is more than the verifier. A structurally valid LLVM program can still implement 2 + 2 as 5. The trust model is structural verifier plus a behavior/contract assertion plus a watched mutation — not the verifier alone.

Cleared to proceed now

Independent of the cutover: land the ownership-reuse work behind its own falsification gates; close the three constructs the Hey emitter still bounces to native; work the fail-closed census into the ledger; and register the coverage receipt as a real gate — a known-red architectural receipt sitting outside every test battery is precisely how a migration silently rots.
