Operators and arithmetic#

Hey's operator set is closed. One machine-readable registry owns spelling, forms, precedence, associativity, overridability, semantic operation, failure behavior, HIR meaning, MIR lowering, and LLVM/runtime implementation.

Complete operator surface#

FamilyOperators
Arithmetic+ - * / % **
Comparison== != < <= > >=
Boolean&& ` and or not !`
Bitwise& ` ^ << >>`
Range..< ..
Spread/rest...
State update= += -= *= /= %= after set only
Postfixmember ., call (), index []

Pipeline, null-coalescing, ternary, &&=, and ||= are not part of the language.

From loosest to tightest:

LevelForms

2not
3``
4&&
5== !=
6< <= > >=
7..< .. and structural ... forms
8``

10&
11<< >>

14**
15prefix !, prefix -, await, spawn

set is a statement, not an assignment expression. State-update delimiters are parsed only in that statement form and do not create Ruby-style assignment-expression ambiguity.

Important groupings:

!a == b       # (!a) == b
not a == b    # not (a == b)
a && b || c   # (a && b) || c
a and b or c  # (a and b) or c
left.mask & right.mask
items[index] << shift

The parser records these structures. HIR, MIR, and LLVM never split source text to rediscover them.

Arithmetic behavior#

2 + 3 * 4
10 / 3
7.5 % 2
2 ** 8

Whole-number division truncates toward zero:

-7 / 2  # -3

Whole-number division by zero is an error. Decimal division follows floating-point rules; converting a non-finite decimal to a whole number is an error.

Whole-number overflow widens rather than silently wrapping:

9223372036854775807 + 1
# 9223372036854775808

Math.pow and ** preserve a whole result when the mathematics stays whole. Fractional or negative exponents may produce decimals. A complex result is rejected rather than silently producing a complex value or NaN.

Exponentiation is non-associative:

2 ** 3 ** 2  # syntax error: parenthesize the intended reading

Write (2 ** 3) ** 2 or 2 ** (3 ** 2) explicitly.

Boolean operators#

All boolean forms short-circuit. && and || are value-oriented tight forms. and and or share the lowest precedence and are readable control-flow forms. not is intentionally looser than comparison; ! is tight.

Bitwise operators#

Bitwise operators use whole-number semantics:

0b1100 & 0b1010  # 0b1000
0b1100 | 0b0011  # 0b1111
0b1100 ^ 0b1010  # 0b0110
1 << 5           # 32
32 >> 3          # 4

Field access, calls, and indexing bind before surrounding bitwise operations. Shifts bind tighter than &, which binds tighter than ^, which binds tighter than |.

Ranges and spread#

1 ..< 5  # 1, 2, 3, 4
1 .. 5   # 1, 2, 3, 4, 5

[...items, next]
{...record, status: 'ready'}

... is also the rest/spread spelling in parameters and calls. Parser context selects the structural form.

State updates are statements#

Ordinary bindings never change:

let count = 0
set count += 1  # error: count is a fixed binding

An actor-owned state slot may change while the owner processes a message:

actor Counter
  state count = 0

  receive message
    set count += 1
  end
end

The target must be private state owned by an actor, monitor, or supervisor. Locals, parameters, object fields, list elements, module bindings, and globals are not update targets.

Module-provided operator meaning#

module MathExtensions
  fn pow(base, exponent)
    # implementation
  end

  exposes pow forms: [:qualified, :unqualified, :infix] infix: '**'
end

An import may select which binding supplies an overridable symbol in one file. It never changes that symbol's spelling, precedence, associativity, or operand form.
