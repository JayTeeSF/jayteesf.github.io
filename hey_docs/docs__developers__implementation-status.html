Implementation status#

The public manual describes the settled Hey language contract. This page explains how implementation and release availability are reported without weakening that contract.

Authority rule#

One frontend owns tokenization, final syntax, resolved names, module surfaces, receiver calls, operator bindings, and source diagnostics for every execution lane.

Frontend authority is eligible only when:

  1. tokenizer, final-syntax, and resolved-name facts are identical across interpreter, Stage-0 recovery, LLVM-direct, self-host, and REPL lanes;
  2. generated compiler-node readers use scoped borrows with zero local snapshot clones while every escaping value remains explicitly owned;
  3. CLI, web, iOS, Android, and AppleTV compile receipts exercise the same facts;
  4. scaling evidence has no unresolved superlinear copy mechanism; and
  5. the compatibility frontend cannot be selected silently as a product fallback.

docs/publication-status.tsv is the publication-time availability record. A transition state adds one site-wide notice. A stable state removes that notice; language pages do not change.

Settled source contract#

  • Modules end with explicit exposes declarations; facade modules may use exposes *.
  • Bare imports provide qualified access. as renames a module, exposing: adopts selected names, old as new aliases a selector, forms: narrows supported forms, and conceals: removes adopted/default names.
  • Imports never re-export implicitly, and runtime Module.load(...) never creates lexical names.
  • Receiver calls resolve statically and insert the receiver as argument one.
  • Callable-field versus imported-receiver conflicts follow lexical nearest/latest selection and produce a warning with both locations.
  • The closed arithmetic, comparison, boolean, bitwise, range, spread, call/member, and state-update operator set has one parser-owned precedence table.
  • Ordinary bindings stay immutable; set updates only actor, monitor, or supervisor state slots.
  • Tokenizer, parser, and resolver diagnostics retain source spans before HIR.

Reusable import surfaces are ordinary facade modules. A separate compile-time selector-manifest feature remains deliberately deferred until a concrete use cannot be served by a facade.

One compiler path#

source and import graph
  -> tokens
  -> final syntax
  -> resolved names, module surfaces, and operator bindings
  -> structural semantic HIR
  -> ABI MIR
  -> mechanical LLVM
  -> native executable

No lower stage reopens raw source to rediscover precedence, receiver structure, import meaning, argument binding, or operator semantics.

Evidence#

Current measured evidence belongs in the published dailies and repository gate ledger. The standing Decisions, Architecture, and Plan remain normative. The parallel-campaign build report is the publication-time evidence checkpoint for this documentation revision.
