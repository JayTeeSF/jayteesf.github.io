Hey 547a: the cross-unit frontier is closing.

Six slices landed on trunk this cycle. Together they carry the resolver's cross-unit call signatures through the MIR as semantically neutral facts, let the Hey-owned emitter lower them mechanically, and route a resolved boxed comparison through Hey's own value semantics — no name re-inference, no first-class runtime modules. Self-host emitter coverage of the example corpus is now 111 of 132. This report updates the compiler track of the ladder; the runtime, performance, and product tracks are unchanged since the 533a full ladder and are not re-measured here.

Current landed source: 0.99.547a at 2e6313f8 (branch trunk) Version stamp: bumped to 547a under the differential-verify standard Article status: current truth, not a release announcement

TL;DR

  • Verdict: the cross-unit call boundary — the swath that dominated the non-covered corpus — is crossed. The Hey-owned emitter now lowers imported Module.method(...) calls from resolver facts, and coverage moved 104 → 111 examples over the campaign, +2 this cycle.
  • Mechanism: HeyNames resolves each imported callee and its signature; a pre-codegen pass writes that as a neutral extern <link_name> <provider> <ret>|<params> row in the MIR; the emitter consumes it mechanically and routes the call through the runtime facade dispatch. The MIR stays the single source of truth; how it lowers is a backend choice.
  • Latest slice: a resolved boxed expression in comparison position — say bool Bits.bit_at(x, 2) == 1 — now enters the same relational path used everywhere else, comparing by Hey's own value semantics rather than by the literal's spelling. That flipped bits_flags and bloom_filter.
  • Language ruling: modules are not first-class runtime values (Option A). Collections.empty(Graph, true) in the MIR was only receiver-sugar for the real source call Graph.empty(true); a resolver-informed pass now canonicalizes it back before codegen.
  • Precedence, learned the hard way: the extern route must yield to native runtime intrinsics (Crypto.encrypt, Bytes.from_text). Routing those through the uniform-boxed facade ABI corrupted their typed byte arguments; a differential against the parent baseline caught it, and the fix reinforced why the extern fact must stay semantically neutral.
  • Falsification: every slice is mutation-proven, and the whole compiler-contract lane is byte-identical to the parent baseline (25 pre-existing failures, zero introduced). The 547a stamp was applied under the differential standard, not absolute-green.

The invariant this cycle established

Canonical MIR handed to codegen must not carry a module namespace as an ordinary runtime argument merely because HeyHir's receiver sugar rewrote a genuine Module.method(rest) call into Collections.method(Module, rest). HeyHir applies that sugar uniformly to value and module receivers and cannot tell them apart single-unit. Only with the resolver's cross-unit proof can the two be separated — so the correction lives in a resolver-informed pass before codegen, never as an emitter reversing semantics. A real value receiver (items.map(f)) is left untouched; only a resolver-proven module receiver canonicalizes. This is enforced and mutation-proven.

The comparison-position slice extends the same discipline: rather than grow a per-literal coercion matrix in the emitter, a resolved boxed operand is lowered to its result value and compared by Hey's own runtime value semantics — the same authority hey_compare_raw uses at runtime. The arm fires only for a complete resolved-extern-call operand with a boxed return kind, so it never intercepts an existing shape.

The broader ruling: modules stay compile-time only. The characterization confirmed the source never treats a module as a value — never stored, returned, compared, or dynamically selected. Introducing first-class runtime module objects merely to clear eight compiler examples was rejected; the resolver already knows exactly which module each name denotes.
