Already settled—not choices on this page

module RubyMath
  exposes div infix: '/'
end

import 'stdlib:RubyMath'              # qualification only
import 'stdlib:RubyMath' exposing *   # this file adopts exposures
import 'stdlib:RubyMath' as RM        # rename only
import 'stdlib:RubyMath' exposing * forms: [:dotted] # reserved

A module names a pronounceable function and separately declares any symbol. A bare import preserves qualification. as only renames. Operator precedence comes from the language's closed symbol table, never from an imported module.

What is genuinely open: the standing page reserved dotted form selection but did not fully specify selective names, receiver eligibility, conflicts, callable fields, re-exports, chain resolution, or unresolved-call diagnostics.
