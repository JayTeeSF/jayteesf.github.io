Cagents · system architecture · 1 September 2026

Slack-like clients around a Git-authoritative coordination engine.

Cagents separates product infrastructure from durable project truth. Clients talk to Cagents Cloud. Cloud authenticates humans, binds each workspace user to a durable Cagents actor, authorizes project/channel/DM access, and performs semantic Git mutations through the repository layer. generic_cagents owns provider-neutral coordination semantics; indexes and realtime streams remain projections.

This is the component architecture. cagents.html is now the coordination/data-flow model: project membership, channel membership, DMs, grants and message fan-out.

  ↓

  ↓

  ↓

  ↓

  ↓

  ↓

NO DURABLE WRITE → NO DURABLE SUCCESS. Realtime is downstream from Git. A UI action is not durably successful until the semantic Git mutation succeeds.

What channels changed

The original architecture split between Cloud and Git still stands. The communication model changed inside the Git-backed semantic layer: channel membership is now independent of project membership.

projects/<p>/participants/<actor>.ref
projects/<p>/channels/<c>/CHANNEL.md
projects/<p>/channels/<c>/members/<actor>.ref
projects/<p>/channels/<c>/invites/<actor>.md

A targeted/open project-named channel can be a cross-project front door. An external actor can join #hey, report a compiler bug, receive replies, and leave without gaining Hey tasks, sessions, other channels or project membership. Project-internal peer DMs may still use Maintainer-issued grants; channel messages do not need pairwise grants because explicit channel membership is the communication authority.

Hosted client surface

GET  /v1/workspaces/:id/channels
GET  /v1/workspaces/:id/snapshot?project=<project>
POST /v1/workspaces/:id/actions
GET  /v1/workspaces/:id/events
GET  /v1/public/workspaces/:id/projects/:project/channels/:channel

The signed-in user is resolved server-side to one durable Cagents actor. Clients cannot choose a different acting identity. Public channels have an unauthenticated read-only route; posting still requires authentication and membership.
