Reflection#

Reflection reports compiler-owned callable and module metadata without changing lexical scope or exposing backend addresses.

import 'stdlib:Reflection' \
  exposing: [function, arity, source, source_location] \
  forms: [:dotted]

fn greet(name)
  return "Hello, #{name}"
end

program
  says greet.function()
  says greet.arity()
  says greet.source_location().path
  says greet.source()
end

Callable reflection uses zero-argument receiver forms with parentheses. That keeps ordinary fields unambiguous: record.arity reads data, while greet.arity() inspects a callable.

Equivalent qualified calls are:

Reflection.function(greet)
Reflection.arity(greet)
Reflection.source(greet)
Reflection.source_location(greet)
Reflection.function_name(greet)
Reflection.module('MyModule')

Callable metadata#

A callable record includes its canonical name, kind (function, worker, or actor), arity, owning module, source text when retained, and source location. Missing optional source text returns nil; it never leaks an internal sidecar or JSON error.

Reflection is observational. It cannot mutate code, bypass module visibility, or change compilation.

Module surfaces#

The resolver and Reflection consume projections of the same module exposure facts. For each public binding, Reflection reports:

{
  name: 'map',
  original_name: 'map',
  kind: 'fn',
  arity: 2,
  forms: [:qualified, :unqualified, :dotted],
  symbol: nil,
  source_location: {path: 'stdlib/List.hey', line: 162}
}

An infix exposure also reports its fixed language symbol. Private helpers are absent. Re-exported bindings retain their original identity and the facade exposure that made them public.

let list_info = Reflection.module('stdlib:List')
says list_info.exposures

stdlib:BuiltIns is the outer lexical module surface. Its bindings are concealable and participate in the same collision diagnostics as explicit imports.

Source and distribution metadata#

Compiled programs receive source-bound reflection metadata beside the executable. REPL declarations retain <repl> locations; imported declarations retain their real source path. SDK and application builds preserve the same record shapes, so tooling does not depend on the caller's working directory.

Runtime Module.load(...) is separate. It returns a module value and does not create lexical names, receiver forms, or operator bindings.

The resolver and Reflection consume the same authoritative exposure records. See Implementation status for release availability; the Reflection shape above is the stable contract.
