The import model is settled. Four edge choices remain.

Receiver position, lexical shadowing, public/private boundaries, automatic supported forms, conceals, built-ins, reflection metadata, and chain resolution are no longer questions. This page asks only the four choices that still change source code or diagnostics.

Verdict first: Hey can support account.deposit(25) without classes or runtime method lookup. Imports determine a lexical candidate set; the resolver rewrites the call to deposit(account, 25); HIR stores the selected binding. The remaining choices are collision and selector ergonomics.

Already settled — do not vote again

  • The receiver is argument one; every other argument stays in order.
  • Inner lexical scope wins; at one scope, the later declaration wins.
  • Every shadowing override emits a compile-time warning with both locations.
  • as renames the module namespace; exposed bindings may also be renamed.
  • Every module ends with an explicit exposes surface.
  • Private helpers remain callable inside their defining module.
  • Adopted exposures automatically enable the forms the module declares.
  • forms: narrows adopted forms; conceals removes selected ones.
  • stdlib:BuiltIns is the implicit outermost exposure and is concealable.
  • Reflection.module must report public names and supported forms.
  • Each segment of a receiver chain resolves independently.
  • Runtime executes the direct chosen call; it does not resolve imports.

What the research changed

C# demonstrates the first-parameter static-call model. Kotlin demonstrates statically resolved extension syntax. Elixir and Haskell demonstrate lexical selective imports, hiding, explicit public surfaces, and private local helpers. Rust makes the callable-field collision visible by requiring parentheses for a field call. Python keeps programmatic module loading separate from lexical import syntax.

Hey authority: standing decisions · full restructure ladder. Primary sources: C# extension members · Kotlin extensions · Elixir imports · Haskell modules · Rust field calls · Python programmatic imports.
