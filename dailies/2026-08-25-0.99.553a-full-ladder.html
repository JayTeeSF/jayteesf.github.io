Hey 553a+: the stamp stood still; the ladder moved.

The source still reports 0.99.553a, but that suffix no longer describes the amount of software behind it. Many compiler, module-system and distributed-runtime commits landed after the 553a stamp. This page treats 553a as the version label and the current source snapshot as the actual state.

Version stamp: 0.99.553aSoftware state: 553a + post-stamp commitsPrimary thread: P2 / one true compiler
Publication correction. The older 553a ladder was essentially a Track-C2 release note. It is now too narrow. This replacement preserves that performance win but treats the post-stamp compiler architecture, the now-implemented module surface, and Distributed Hey as first-class ladder tracks.

TL;DR

  • The compiler architecture materially advanced without a version bump. Authoritative compilation now has a resolve-once ProgramResolution artifact before HIR, exact full-span call identities, a compiler-owned typed-intrinsic registry, and a deterministic L1 provider-closure manifest. The next P2-LINK rungs are compile/link providers, direct hey_fn_Module__fn calls, and one program-wide callable dispatcher.
  • The language surface did change. Modules now have an explicit public surface: exposes, import as, exposing:, selector aliases, forms:, conceals:, and explicit re-export. These are lexical compile-time rules, not runtime module lookup.
  • Distributed Hey is real software, not a sketch. Codec, DistTransport, DistNode, DistRemote, immutable RemotePid, send/call/monitor semantics, stale-incarnation rejection, and a real macOS↔Linux TLS gate exist. Raw IO handles now have an explicit move-only actor crossing via Io.into_actor; ordinary handle sends are rejected.
  • Performance truth is more nuanced than the old 553a page. String self-append remains O(n) for the proven accumulator shape. The interprocedural map-update mechanism remains landed, but the honest 1BRC result is reopened because method-form stats.put(...) was not yet unified with builtin put(...) for ownership analysis. Native floating point also has a correctness bug, so it outranks perf polish.
  • P2 is not done until behavior is right. “Emits through the Hey-owned compiler” is not enough. The close gate is 132/132 builds and executes correctly, fallback 0, FAILBUILD 0, distributed examples 01–06 through the default native compile, then the native macOS↔Linux TLS gate.

What changed after the 553a stamp

ProgramResolution became a real compiler artifactVersioned, deterministic, exact-span resolved-call records and signatures are produced once upstream. HIR and the extern projection consume the same semantic truth.
Intrinsic knowledge moved out of emitter folklorecompiler/typed_intrinsic_registry.json is the declaration source; generated Hey/C/JSON projections are drift-gated and backend completeness is checked.
P2-LINK got a concrete architectureArchitecture C separates static module stance, resolver-derived program need, and the final L1 link plan. One closure artifact is meant to feed linking, direct-call lowering and callable dispatch.
Callable ABI was narrowed, not redesignedA callable is already a boxed HeyValue* at the machine boundary. No new ABI letter and no runtime name→function table are required.
The module system became explicitPublic surfaces and import forms are resolver-owned, source-visible contracts rather than “module import means everything appears.”
Actor IO gained an ownership storyRaw sockets/TLS handles are no longer allowed to silently ref-share across actors: ordinary sends reject them; explicit transfer is move-only.

Language surface: the module update is real

module BankAccount fn deposit(account, amount) return {...account, balance: account.balance + amount} end exposes deposit forms: [:qualified, :unqualified, :dotted] end import './bank_account.hey' as Accounts import './bank_account.hey' exposing: [deposit] forms: [:dotted] import 'stdlib:Json' exposing: [generate as stringify] import 'stdlib:BuiltIns' conceals: [length]

The resolver decides all of this before HIR. Bare import is namespace-only. as renames the namespace. exposing: adopts selected bindings; forms: narrows qualified/unqualified/dotted/infix use; selector aliasing uses old as new; conceals: removes adopted/default names. Re-export is deliberate through an exposing facade and exposes *.

Distributed Hey: what is implemented vs what is still blocked

Implemented and exercised

  • Codec: versioned tagged binary encoding with limits.
  • DistTransport: framed streams, handshake, heartbeat, compatibility rejection, counters/backpressure.
  • DistNode: node identity/incarnation, server routing, monitor lifecycle.
  • DistRemote: immutable RemotePid, at-most-once send, correlated call/reply.
  • Stale-incarnation rejection.
  • Real macOS↔Linux two-machine TLS gate from the 551a milestone.
  • Io.into_actor explicit move-only top-level handle transfer.

Deliberately not called finished

  • The compiler must build distributed examples 01–06 through the default native path with no semantic fallback.
  • Then the same native binaries must pass the local distributed gate and the real two-machine TLS gate.
  • Registry/Jobs/cluster membership and richer distributed supervision remain frozen until that compiler gate is green.
  • Nested IO handles are not recursively moved in actor-owned-IO v1; the transfer is explicit and top-level.

Glossary

553a+
The version string is still 0.99.553a, while the described source snapshot contains substantial later commits.
ProgramResolution
The resolve-once, deterministic semantic artifact shared by downstream compiler projections.
P2-LINK
The replacement for pure-Hey cross-unit JSON/subprocess delegation: compile providers, link their hey_fn_* symbols, emit direct calls.
L1 closure
The deterministic program-specific set of pure-Hey providers that must participate in the final link.
Architecture C
Static module stance says what a module is; resolver says whether this program needs it; L1 says what this program links.
RemotePid
An immutable remote actor reference carrying node identity/incarnation plus actor identity; never a pointer into remote memory.
Io.into_actor
Explicit one-owner transfer of a top-level raw IO handle into an actor; source is poisoned after a successful move.

Status vocabulary: implemented = code exists; landed = committed; verified = a named gate reproduced the claim; active = the mechanism is still being changed; held = intentionally frozen behind another gate. This page is a software-state snapshot under the unchanged version stamp 0.99.553a.
