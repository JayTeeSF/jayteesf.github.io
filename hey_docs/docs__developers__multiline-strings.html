String literals and multiline text#

Hey provides concise raw and interpolating forms for both short and long text.

Ordinary strings#

Single quotes are raw: #{...} and backslashes stay literal except for \' and \\. Double quotes support escapes and interpolation.

let name = 'Ada'
says 'raw #{name} and "quotes"'
says "Hello #{name}\n"

Percent strings#

Use %q when a raw one-line string contains both quote styles. Use %qq or %Q when interpolation is wanted. Paired delimiters nest.

let name = 'Ada'
says %q(raw 'single' and "double" quotes; #{name} stays text)
says %qq(Hello #{name}; both 'single' and "double" quotes are easy)
says %Q[paired delimiters [may nest] for #{name}]

%qq is Hey's explicit interpolating partner to %q; %Q is accepted for Ruby familiarity. Any non-alphanumeric punctuation delimiter may be used.

Interpolation expressions#

Interpolation accepts ordinary expressions, including indexed values, function calls, and nested object literals. Quote normalization inside #{...} follows the same rules as surrounding Hey source.

import 'stdlib:Text'

let profile = {name: 'Ada'}
says %Q(profile=#{profile.name})
says %qq(nested=#{Text.upper(profile.name)})

Heredocs#

Use <<TAG for indentation-preserving interpolated text and <<~TAG for a squiggly heredoc that removes common leading indentation. Quote the tag with single quotes to keep #{...} raw; a double-quoted tag remains interpolating.

let name = 'Ada'
print <<~HTML
  <h1>Hello #{name}</h1>
  <p title="both quote styles are ordinary text">Welcome.</p>
HTML

print <<~'SHELL'
  archive="$HOME/Downloads/app.zip"
  echo '#{not_interpolated}'
SHELL

Heredoc bodies preserve their final newline, matching shell/Ruby expectations. Use print when the block already carries its terminating newline; says adds another newline by design.

Heredocs and multi-line statements#

Statements also continue across lines while a (, [, or { opened in the statement is unclosed (see the language reference). Heredocs are unaffected by that rule: a heredoc body is text, so braces, brackets, and parentheses inside it never open or close a continuation. let bodies are likewise unchanged. Use bracket continuation for multi-line call arguments and literals; use a heredoc when the multi-line content is the text itself.

Triple-quoted strings#

Triple double quotes remain useful for compact inline multiline values with interpolation. Triple single quotes are raw.

let name = 'Ada'
let page = """<h1>Hello #{name}</h1>
<p>Welcome to Hey.</p>
"""

let template = '''Hello #{name}
The interpolation marker above remains text.
'''

All forms normalize into the same ordinary string representation before semantic HIR. They do not create a second runtime string type.

Repository convention#

Use one heredoc-backed print for a block of literal output instead of swapping between several one-line says calls. Keep separate says calls when each line is a distinct computed value or when a spec is explicitly teaching output semantics.
