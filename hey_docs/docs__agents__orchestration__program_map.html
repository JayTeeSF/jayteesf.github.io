SECURITY IS A TRACK NOW (maintainer directive 2026-07-28)

The stdlib SIDECAR — the helper process the runtime spawns for

stdlib calls the compiler cannot yet emit natively — is NOT a

security boundary: same uid, same rights, so separation without a

privilege drop buys no containment. Published analysis:

jayteesf.com/articles/what-is-on-the-other-side-of-the-pipe.html

BINDING ON EVERY AGENT as STANDING RULES 16-22 in

orchestration/agent_standing_rules.md (commit 6e726b17) — the file

every brief cites, so it arrives by default and not by anyone

remembering. Read it before touching resolution, spawning, or

delegation.

THE ROOT PATTERN, and it is the same one WIDEN THE FIX exists for:

both resolvers feeding the sidecar spawn FAIL OPEN — they walk off

the end of their ladder into the current working directory instead

of refusing. One cause, three symptoms already collected:

performance (HEY_ROOT unset => silent ~150x, linux hazard 7),

correctness, and security (measured code execution, both lanes).

IN FLIGHT: wresolve — ONE hardened resolver, both call sites,

refuses instead of defaulting; posix_spawn not posix_spawnp;

access/spawn TOCTOU closed; permanent negative-controlled gate.

QUEUED, NOT CLOSED BY IT: sidecar LIFETIME (a two-body fix —

PR_SET_PDEATHSIG on Linux, kqueue NOTE_EXIT/getppid on Darwin,

which has no equivalent primitive; gate must use the recorded-

parent-pid predicate, NEVER ppid==1, which false-negatives under a

systemd subreaper); the bounded helper pool; privilege drop.

THE DURABLE FIX IS NARROWING, NOT SANDBOXING: every stdlib name

lowered natively can never reach the delegation path at all, so the

S1 lowering-consistency program is a SECURITY deliverable as much

as a performance one. "Sandboxing a helper that still has to do

everything is how you get a sandbox with every door propped open."

DISCLOSURE: architecture piece published; the path-resolution

vector publishes WITH the fix. Outcomes, not recipes, until then.

inject names into the importer's namespace BY DEFAULT. RULED:

default import must be namespaced-only; injection becomes

opt-in. SPELLING RULED (maintainer, 2026-07-28):
