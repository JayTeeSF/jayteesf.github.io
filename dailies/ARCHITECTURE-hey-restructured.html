The intended semantic join point. The legacy path remains authoritative; candidate HIR receipts require clean regeneration.

Hands forward: resolved Hey semantics
incomplete

6. Application MIR

Reachable program closure, representation types, instructions, ownership, boxing, and explicit control flow.

Must contain all imported bodies needed by the app
correctness gap

7. LLVM emission

A mechanical printer over MIR. Boxed conditions currently expose a truthiness defect.

Must never parse or repair missing program meaning
existing

8. Link + runtime

Native executable plus one value model, actors, builtins, I/O, generated-node ABI, and borrow lifetime ABI.

Shared by interpreted and compiled consumers

Interpreter and REPL

The target is a shared HIR walker. Today the REPL can execute the candidate receipt, but the old interpreter path has not yet been replaced by that shared consumer.

consumer B

Structural HIR lowers to application MIR, then LLVM text, link, and the same runtime. LLVM-direct and self-host application receipts are currently blocked on module closure.

Current contracts and blockers

Module closureprimary identity blocker

Resolution is not enough. The compiler must turn the resolved module graph into one complete application program containing each reachable imported body exactly once. LLVM-direct and self-host must consume that same complete MIR; neither may reread source to repair it.

SOURCE UNITS + IMPORT GRAPH
    → RESOLVED BINDINGS
    → REACHABLE MODULE-BODY CLOSURE
    → ONE APPLICATION HIR
    → ONE APPLICATION MIR
TruthinessLLVM boxed condition defect

Truthiness is a language operation, not numeric conversion. A boxed non-empty string must not become false because a numeric conversion routine applies strtol. Ordinary and borrowed values must share one truthiness primitive across every executable lane.

Generated-node readscutover active

Exact compiler nodes store physical n_ slots only. Reviewed logical introspection resolves through generated stable field IDs. Generic JSON lookup does not alias logical and physical names. Minimal self-host one-operand scoped borrowing now compiles through a cold self-rebuild; full lifetime parity is still pending.

Evidence integrityclean revalidation required

Three lanes execute the candidate receipt, but cached reruns previously allowed a no-HIR placeholder to contaminate the digest. The repaired identity gate must exclude declared non-applicable rows from comparison while a separate correctness gate keeps the underlying unknown-field failure red.

Corrections carried forward from the original diagrams

  • Unary versus binary - is a parser decision from grammar context. The tokenizer emits one minus token.
  • Tokenizer, final syntax, and operator-registry foundations are no longer “missing”; they are candidate or partial and are not authoritative.
  • The self-host compiler can lower a minimal one-operand scoped read through a cold self-rebuild. Its application receipt is blocked elsewhere: imported module bodies are absent from the completed application program.
  • The local-reader denominator is 190, not 194; 153 are scoped and 37 remain compatible. Owned escapes are 260 of 260 explicit.
  • Three lanes execute the candidate receipt, but clean identity evidence must be regenerated after the cached-placeholder HIR defect.
  • The exact operator row/column count is not frozen into this architecture page. The normative generated registry and its drift receipts own that number.
