Hey 552a: the interprocedural map cliff falls.

The last dictionary O(n²) is closed. The interprocedural map update — set stats = merge(stats, k, v), the shape at the heart of an honest 1BRC — was still deep-cloning the whole map on every update through 551a. 552a removes it with a general MIR ownership fact plus an in-place put for a consumed param in both emitters: the map is now reused in place, O(1) per update. Distributed Hey, landed and run across two physical machines at 551a, stays closed; string self-append is the single remaining O(n²).

TL;DR

  • The 1BRC map cliff is removed. The 549a in-place map put was conditional — licensed only when the map was read via has?/get/keys in the same function. The interprocedural shape set stats = merge(stats, k, v), where merge reads via has?/get and rebuilds via put (the 1BRC aggregation), still deep-cloned the whole map every update — so 1BRC stayed ~4300× C (≈8564 ms / 100k rows) through 551a. 552a makes it reuse the map in place.
  • How (a general fact, not a benchmark hack): a generalized consume-transfer analysis — a callee consumes its param when every return consumes it (put/push(p0,…)) or returns it unchanged, every other read is a non-retaining borrow (has?/get/keys/len), and it is never aliased/stored/passed as a value — plus an in-place put for a consumed param in both emitters (the twin of the existing in-place push). Wiring it makes merge earn a ; consume and the caller a ; move; the ownership verifier is automatically in lockstep (it recomputes through the same pass — it accepts a legit authorization and rejects a forged one).
  • Receipt (flat, O(1)/op): the interprocedural-merge K-sweep (N=200000 updates, best-of-3) is flat across map size — K=100 0.06s, K=1000 0.06s, K=2000 0.06s — versus the pre-fix O(map) of 0.82s → 14.2s (~237× at K=2000). Clones are now O(N), not O(N·map) — the collection is no longer cloned. COW-on == COW-off (HEY_RC_COW=0, RC-assert no abort); HIR/MIR goldens unchanged; ownership specs green; the cross-language bench is re-measuring the full 1BRC-vs-C.
  • Both dictionary O(n²) mechanisms are now closed. 549a closed the in-place map overwrite (~122×/~39× on W9/W10, re-measured); 552a closes the interprocedural map update (the 1BRC shape). The single remaining O(n²) is string self-append (s = s + x) — a representation problem (Track C2), now under a ruling (below) and in progress. Not claimed fixed.
  • Distributed Hey stays closed. At 551a the v0 substrate landed and the two-machine TLS L2 gate went green across all four legs on real hardware (macOS ↔ Linux over ethernet), with a published how-to; nothing regresses here. The main engineering thread has returned to the compiler.

The 1BRC map cliff, removed

The honest 1BRC aggregates per-station stats through a helper — set stats = merge(stats, station, temp), where merge is if m.has?(k) return put(m, k, m.get(k)+v) end; return put(m, k, v). Through 551a each update deep-cloned the whole stats map (the 549a in-place reuse was only licensed for a same-function has?-guarded overwrite, not this interprocedural rebuild). 552a reuses the map in place. How the interprocedural fix works

The cliff had two conservative limits, both lifted together (a ; move without an in-place consume would leak, so they land atomically under the verifier):

  • The analysis was too narrow. The 549a consume-transfer summary accepted only the trivial shape — a single ret put/push(p0, x) with p0 read exactly once. merge fails it on both counts (two returns; m read via has?, get, and put), so it never earned the authorization. The generalized rule: p0 is consume-transfer when every return consumes it (put/push(p0,…)) or returns it unchanged, and every other read of p0 is a non-retaining borrow (has?/get/keys/len), and p0 is never aliased, stored, or passed as a value argument. Read-count is the wrong test; consumed-once-per-path with borrows allowed is the right one.
  • The emitter had no in-place put. The callee-consume path already lowered an in-place push for a consumed param, but a put on the same consumed param still called the cloning shim. 552a adds the twin — hey_llvm_json_put_value_owned in the runtime, selected in both the self-host and native emitters when the put target is the consumed param.
  • The verifier stays honest for free. It recomputes the authorization by re-annotating a stripped MIR through the same weld pass, so wiring the general predicate keeps it consistent: a legit ; consume survives the recompute; a hand-forged one on a function the recompute would not authorize is rejected (“analysis recompute disagrees”).

This is a general MIR ownership fact — it helps any reduce-over-a-map merge, not just 1BRC — and it is kept named apart from the string-concat problem and the compiler-authority receipts.

Track C2 — the last O(n²), ruling made

With both dictionary levers closed, s = s + x is the only O(n²) left. It is quadratic because a str accumulator is a raw C-string: each + manufactures a fresh string value from the whole prefix before the concat can help, so the persistent thing is the char*, not a refcounted backing — which is why the ownership machinery above cannot reach it. It is a representation problem, and after a read-only census the ruling is made: a narrow persistent-owned-string slot for compiler-proven string locals that must preserve a refcounted HeyString backing across ownership-preserving transformations — keyed on that semantic distinction, not on a variable name, a benchmark, or the + operator. The ordinary str ABI (raw cstr, and materialization at real ABI boundaries) is unchanged; this is not a language-wide owned-string conversion. Implementation is in progress; it is not claimed fixed here.

Distributed Hey — closed at 551a

Nothing on the distributed track changed this cycle; it is recorded here as last-verified. At 550a the v0 substrate landed as four attributable layers — native TLS server accept, a versioned binary Codec (measured O(n) encode), and the DistTransport/DistNode/DistRemote substrate with node identity + incarnation, backpressure, heartbeats, reconnect and remote monitors — and stale-incarnation rejection was enforced and falsified. At 551a the two-machine TLS L2 gate went green across all four legs on real hardware: a macOS node and a Linux node over fast ethernet ran Remote.call (TLS, reply=pong), Remote.send (tcp, at-most-once), the kill→NODE_DOWN monitor (tcp), and stale-incarnation rejection (TLS) — node A observed exactly the incarnation node B advertised, a genuine cross-host run. Two showcase demos (05_mandelbrot across four worker nodes with real per-tile attribution; 06_wordcount MapReduce) and a minimal Dashboard.hey shipped alongside, with a published “How to run distributed Hey” walkthrough that includes a verified Docker two-container recipe. Examples run interpreted (the LLVM backend does not yet lower the cross-unit Dist*/Codec calls); the remaining rungs are the deterministic L3 partition / at-most-once matrix and a cluster registry. v0 guardrails held: no Registry/Rinda/Jobs/gossip, at-most-once with no auto-replay, and socket IO stays in its owning context (a documented deviation with a filed follow-up).

Verification & falsification

The version at stdlib/Version.hey now reads 0.99.552a; version-smoke is green and the 48 HIR/MIR goldens were regenerated to 552a (version-line-only, no body drift). The compiler levers carry their own mutation contracts and the differential-verify standard.

  • The 1BRC map fix is proven, not just fast. The generalized analysis is mutation-proven (spec 1352): the merge shape earns the authorization, while the value-arg, non-consuming-return, and alias negatives are refused. The verifier rejects a forged ; consume (spec 1353). The existing ownership specs (1189, 1346–1351) are unperturbed, and the HIR/MIR goldens are unchanged (no golden fixture carries the general-consume shape).
  • Soundness receipt. On the interprocedural-merge probe the native run is correct, the emitted IR uses the in-place put_value_owned for the consumed param, clones drop to O(N), and the answer is identical with COW on and off (HEY_RC_COW=0, RC-assert no abort). Wall-clock is not the proof — the flat K-sweep and the clone counts are.
  • Distributed, carried: the 551a two-machine gate and the frame-falsification suite remain green; honest failure detection (partition and death are observationally indistinguishable) and at-most-once delivery are unchanged.
