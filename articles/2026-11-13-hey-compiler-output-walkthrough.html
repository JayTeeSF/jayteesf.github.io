Fix the boundary in dependency order

  1. Build the numeric module surface: local exports, explicit and wildcard imports, facade re-exports, privacy and selector-rename policy.
  2. Attach namespace spellings to provider identities: aliases and plain namespaces must name the same verified unit.
  3. Project imported declarations into HIR: preserve declaration identity and provider bodies.
  4. Carry cross-unit targets through MIR and LLVM: agree on call ABI, then link and execute legal two-file cases while retaining privacy failures.

Status: proposed order based on this older audit; the latest local-program capture does not recheck imports.

Source becomes typed SSA, then stops before LLVM

The abstract syntax tree (AST) records program structure. High-level intermediate representation (HIR) records resolved identities and inferred types. Mid-level intermediate representation (MIR) records typed values and control flow in static single assignment (SSA) form: each value has one definition.

How does a value's range move through the graph?

The analyzer queues a value when one of its inputs changes, then revisits only the values that depend on it. A loop can send a value back to an earlier block and expand its range. At cyclic joins, an expanding bound becomes unbounded; unchanged bounds retain their known values. This widening lets the queue settle without an arbitrary iteration cap.
