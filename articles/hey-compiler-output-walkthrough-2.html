How the captured artifacts map onto the eight-stage pipeline

Source text ends at HeyTokens.hey. Every boundary afterward passes structured Hey records or sealed-block static single assignment (SSA) graphs (Compiler 1 §1):

  1. 1–2 · AST & CoreHeySyntaxTree + HeyNames (unit_id, node_id)
  2. 3 · Tree HIRHeyHir + HeyHirInference (#TypeTuple)
  3. 4 · SSA-MIRHeyMirSsa + HeyMirFacts (fits_i64?, block_scopes)
  4. 5–7 · Physical & LifetimesWorkers, HeyStr, borrows, Perceus & arenas
  5. 8 · Verify & LLVMHeyMirVerify -> HeyMirLlvm (native codegen)

Braun sealed-block SSA connects branches and loops through explicit block parameters and edge arguments, preserving nested lexical block_scopes across split critical edges (HeyIr.hey). All JSON captures below serialize those in-memory Hey structures purely for external inspection, just as hey phase admit|hir|mir|llvm does on the command line (Commands Reference).

How does a value's range move through the graph?

The analyzer queues a value when one of its inputs changes, then revisits only the values that depend on it. A loop can send a value back to an earlier block and expand its range. At cyclic joins, an expanding bound becomes unbounded; unchanged bounds retain their known values. This widening lets the queue settle without an arbitrary iteration cap.
