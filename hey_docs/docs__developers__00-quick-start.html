Quick start#

Build Hey#

From a source checkout:

make -j8 build/heyc

Run a source file through the ordinary command:

./bin/hey hello.hey

Build a native executable:

./bin/hey build hello.hey -o build/hello
./build/hello

Your first program#

Create hello.hey:

program
  let user = {name: 'Ada', visits: 1}
  let next = {...user, visits: user.visits + 1}
  says "#{next.name}: #{next.visits}"
end

Expected output:

Ada: 2

user never changes. next is a new immutable object.

Functions and receiver calls#

fn greet(user, punctuation = '!')
  return 'Hello, ' + user.name + punctuation
end

program
  let user = {name: 'Ada'}
  says greet(user)
end

A function exposed for dotted use may also be written with receiver syntax:

user.greet('!')

The resolver turns that into greet(user, '!') at compile time. It is not runtime method lookup.

Modules#

A module explicitly declares its public surface:

module Greetings
  fn greet(user)
    return 'Hello, ' + user.name
  end

  private fn normalize_name(name)
    return name
  end

  exposes greet forms: [:qualified, :unqualified, :dotted]
end

A bare import adds the qualified module name only:

import './greetings.hey'

program
  says Greetings.greet({name: 'Ada'})
end

Adopt selected public bindings explicitly:

import './greetings.hey' exposing: [greet]

program
  says greet({name: 'Ada'})
end

See Modules and imports for the complete contract.

Arrays and objects#

program
  let names = ['Ada', 'Grace']
  let expanded = [...names, 'Katherine']
  let indexed = {Ada: 1, Grace: 2}

  says expanded[2]
  says indexed.Grace
end

Use dot access for a known field and brackets for a dynamic key:

let field = 'Grace'
says indexed[field]

Operators#

program
  says 2 + 3 * 4
  says 1 << 4
  says 0b1100 & 0b1010
  says true && false || true
  says 1 ..< 4
  says 1 .. 4
end

Operator shape is fixed by the language registry. Imports can supply or override an operator's meaning for one file, but cannot change its precedence or associativity. See Operators and arithmetic.

Embedded specs#

spec 'answer'
  expect stdout "42\n"
end

program
  says 40 + 2
end

Run the spec:

./bin/heyc answer.hey --test
